# Extended Euclidean Algorithm (EEA)
> An extension of the [Euclidean Algorithm](./Euclidean_Algorithm.md) which also finds Bezout coefficients

- Bezout coefficients are the x & y values in Ax + By = GCD(A, B)
    - xGCD will always find the minimal pair

- This algorithm can be used to find the inverses of modulo
- [Example](https://en.wikipedia.org/wiki/Extended_Euclidean_algorithm#Examples)
    - From the example it should be easy to figure out the pattern without explanation
